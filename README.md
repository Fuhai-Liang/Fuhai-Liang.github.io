## 内容管理（怎么加文章）

本版已接入 **Astro 内容集合**，每篇文章 = 一个 Markdown 文件，放在：

```
src/content/posts/
```

首页、项目、经历、视频、生活随记页面都会**自动读取**这些文件，无需改代码。

详细填写方法（frontmatter 字段、分类、粘贴步骤）请看：**《内容填写指南.md》**。

快速开始：

```bash
npm run dev   # 本地预览
npm run build # 正式构建
```
