## Python环境配置（MacOS M2）

打开终端输入

```
python --version
```

检查有没有python

### 打开python官网下载安装

[Python 官网](https://www.python.org/downloads/macos/)  
 直接傻瓜式安装  
 默认路径：

```
/Library/Frameworks/Python.framework/Versions/3.8
```

再次输入

```
python --version
```
